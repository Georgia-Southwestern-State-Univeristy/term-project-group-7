# Final Team Retrospective

## What the Team Did Well

* Maintained a consistent development workflow using Git and PRs
* Successfully implemented CI/CD pipeline
* Delivered a functional end-to-end system
* Kept documentation aligned with development progress

---

## What We Would Change Earlier

* Define architecture earlier in the semester
* Reduce time spent switching technologies
* Improve early test coverage
* Better scope control during mid-development

---

## Most Valuable Engineering Practice

Continuous Integration (CI) was the most valuable practice. It ensured code quality, prevented regressions, and maintained a stable build throughout development.

---

## Most Costly Mistake

Switching from Python to C++ mid-project caused delays and required rework of existing components.

---

## Project Evolution

* **Initial Proposal:** Basic adaptive learning concept
* **Mid-Semester:** Partial implementation with limited structure
* **Final Release:** Complete backend system with API, CI, testing, and documentation

---

## Summary

The project evolved from a conceptual prototype into a structured, working system. The team improved in system design, collaboration, testing practices, and release management.
