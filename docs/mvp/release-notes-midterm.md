# Midterm Release Notes

## Version
midterm-v1.0.0

## Included Features
- C++ backend service
- Health endpoint
- Student profile creation
- Assessment submission
- Recommendation retrieval
- Static frontend page
- Automated tests
- CI pipeline

## Known Limitations
- In-memory storage only
- No authentication
- Limited teacher-facing functionality
- Basic recommendation logic

## Reproducing the Demo
1. Clone the repository
2. Build the project using the README instructions
3. Run the server locally
4. Access the endpoints used in the demo

## Evidence
This release corresponds to the Week 8 Midterm MVP build.
