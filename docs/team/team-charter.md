# Team Charter

## Roles & Responsibilities
- Victor Grey (DevOps / QA):
  Responsible for CI/CD setup, testing, code quality checks, and deployment-related concerns.

- David Hugee-James (Project Manager / Scrum Lead / Documentation Lead):
  Responsible for task coordination, sprint planning, documentation, and ensuring milestones
  align with project requirements.

- Ridhwaan Jimoh (Backend / API Lead / Frontend):
  Responsible for backend logic, API design, and frontend integration for the assessment
  and tutoring flows.

## Communication Plan & Meeting Cadence
- Primary channel: Mobile Phone Group Chat and Email/Teams (team preference)
- Backup channel: GitHub Issues for task tracking and blockers
- Response expectations: Within 24 hours (same-day responses when possible; weekends may roll to Monday)
- Meeting cadence: Weekly sync (30–60 minutes, Central Time)
- Optional check-ins: Async daily updates in chat (did / doing / blockers)

## Definition of “Done”
A change is “done” when:
- PR is opened with a clear description
- At least one reviewer is assigned
- At least one approval is received
- All checks pass (tests/lint if applicable)
- Changes are merged into main
- No direct pushes to main

## Decision-Making Process
- Default decision method: Team consensus
- If blocked for more than 24 hours: Majority vote
- Tie-breaker: Project Manager (David Hugee-James)
- Dispute escalation: Professor

## Contribution Expectations & Accountability
- Weekly expected hours: 4–6 hours per team member
- Minimum weekly deliverable: At least one PR, issue update, or documented contribution
- If someone is blocked: Notify the team within 24 hours via primary communication channel
- If someone misses commitments: Discuss during weekly sync and reassign tasks as needed
