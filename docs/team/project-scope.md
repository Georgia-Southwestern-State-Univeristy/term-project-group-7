# Project Direction & Scope Boundary

## Project Name
Team Task & Async Standup Tracker (Web App)

## Problem Statement & Target Users
Student project teams often struggle with task coordination and consistent communication.  
Tasks are scattered across chats, documents, and memory, while standups are skipped or unstructured.

**Target users:**  
- Small student project teams (mainly 2–6 members)
- Remote or hybrid academic teams

## Core Value Proposition
Provide a single, lightweight web application where teams can:
- Track tasks
- Assign ownership
- Share daily async standup updates

This reduces confusion, improves accountability, and creates a shared source of truth for the team.

## Must-Have Features (Beta Scope)
The beta release could include only the following:
- User accounts (basic authentication)
- Create, assign, and update tasks
- Task status tracking (To Do / In Progress / Done)
- Daily async standup entries:
  - What did you do?
  - What are you doing next?
  - Any blockers?
- Team dashboard showing:
  - Active tasks
  - Recent standup updates

## Explicit Non-Goals
The following features are intentionally excluded from the beta:
- No Slack, Discord, or email integrations
- No push notifications or reminders
- No mobile application
- No analytics or reporting
- No external calendar integrations

## Risks & Constraints
- Authentication bugs or session handling issues
- Scope creep if additional features are added too early
- UI complexity if too much data is shown at once

For risk prevention, the project will remain feature-limited and focus on core functionality only. Once in Beta we can start seeing about other implementations upon having successful interface.
