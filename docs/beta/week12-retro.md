# Week 12 Retrospective

## What Went Well
- Successfully delivered a runnable CLI system
- CI pipeline is working and consistently passing
- Documentation now reflects the actual implementation
- Reproducible run path allows another user to execute the system

---

## What Slowed the Team Down
- Earlier mismatch between planned browser-based system and actual CLI implementation
- Time spent correcting documentation alignment
- Lack of persistence and authentication features limited system completeness

---

## Top 3 Lessons Learned
1. A working system is more valuable than an overplanned incomplete one
2. Documentation must always reflect the current implementation
3. CI and testing must validate real workflows, not assumptions

---

## Top 5 Priorities for Weeks 13–15
1. Implement persistence (save user progress and results)
2. Add authentication and role-based access
3. Fix CLI exit behavior (remove need for Ctrl+C)
4. Expand test coverage including edge cases
5. Improve system structure toward a complete product

---
