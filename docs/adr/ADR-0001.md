# ADR-001: Rules-Based Adaptive Learning Logic

## Status
Proposed

## Context
The system is a locally operated educational software prototype designed to support
middle school mathematics instruction for grades 6–8. The project is intentionally
limited in scope to ensure feasibility within a single academic semester.

The application must provide adaptive learning paths based on student assessment
performance while remaining simple, explainable, and maintainable. Constraints
influencing this decision include limited development time, a small team size, the
absence of large training datasets, and the requirement that teachers understand how
learning recommendations are generated.

While more advanced machine learning or AI-based approaches could provide deeper
personalization, they introduce additional complexity, infrastructure requirements,
and explainability challenges that are not aligned with the project’s instructional
goals or scope.

## Decision
The team will implement a rules-based adaptive learning engine that evaluates student
performance using predefined thresholds and scoring logic.

Assessment results will be analyzed using deterministic rules (such as correctness
percentages, repetition counts, and proficiency gates) to determine whether a student
advances, repeats content, or receives targeted reinforcement.

## Consequences

### Positive Consequences
- Reduced technical complexity and implementation risk
- Faster development aligned with semester constraints
- Fully explainable behavior for educators and reviewers
- Easier testing, debugging, and maintenance

### Negative Consequences
- Less granular personalization compared to AI-driven systems
- Limited ability to detect complex learning patterns
- Manual tuning required for scoring thresholds and rules

### Remaining Risks
- Oversimplified rules may misrepresent student understanding
- Poorly calibrated thresholds could impact learning outcomes
- Future scalability may require revisiting this decision

These trade-offs are accepted as appropriate for a focused instructional prototype
prioritizing clarity, feasibility, and instructional alignment.
